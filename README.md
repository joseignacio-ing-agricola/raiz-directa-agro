# Raíz Directa

Tienda de dropshipping agrícola orientada a Chile. Es una tienda estática lista para desplegar y tiene un catálogo separado para la carga inicial de productos.

## Abrir localmente

Abre `index.html` en un navegador.

## Catálogo

El archivo `products.csv` es la fuente inicial de productos. Antes de vender, reemplaza los SKU de ejemplo con los SKU reales, define el proveedor y confirma precios, disponibilidad, plazos de despacho, impuestos y condiciones de devolución.

## Conectar dropshipping

1. Escoge un proveedor que acepte dropshipping y entregue a Chile.
2. Solicita sus credenciales API, catálogo o feed de stock.
3. Copia `supplier-config.example.json` a un archivo privado que no se suba a GitHub y carga allí las credenciales.
4. Añade un backend o una plataforma e-commerce (por ejemplo Shopify o WooCommerce) para sincronizar inventario y enviar pedidos; no incluyas tokens en el frontend.

## Publicación

El repositorio está preparado para GitHub. Aún no contiene claves ni conexión a proveedor, porque esas integraciones requieren la cuenta y credenciales reales del comercio.
